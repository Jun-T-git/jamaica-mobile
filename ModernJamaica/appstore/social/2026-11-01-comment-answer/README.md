# 答えはコメント欄版：50の試作

利用者の新パターン案と「1本作ってください」の指示による制作。今回は完成MP4と固定コメント原稿の準備までで、YouTubeへ公開・予約していない。既存の予約7本と公開後の固定コメント処理は別。

## 構成

元の5数字4・2・6・4・3で50を作る問題。冒頭2秒の問いかけ、実ゲームの6＋4＝10までの操作、考える時間、「答えは固定コメントへ」の2秒、独立したApp Store検索画面の2秒で構成する。動画の中に正しい式・正解の根・成功ポップアップは表示しない。過去問題とは目標＋5数字の組で照合済み。

固定コメント原稿は次のとおり。式が元の5数字を各1回使い50になることを算術検証する。

> （6＋4）×（4＋3−2）＝50
>
> 他の解き方を見つけた方はコメントで教えてください！

## 再制作・検証

共有rendererのcomment-answerを使用。問題設定・元録画ハッシュ・30fps正規化ハッシュ・答え漏れの確認範囲・途中の演算木・カットはproblemsとsourcesに保存する。最初は離れた数字を結ぶ2操作を収録したが、見やすさと手がかりの量から隣接する6と4の1操作へ絞って再収録した。同じ問題の再収録であり、新しい問題の予約や重複投稿ではない。

素材とMP4・抽出画像はGit外。このローカルフォルダーに保持する。別端末での再編集には原素材が必要。画面の抽出確認・全フレームのデコード・音量測定と、実再生・音声試聴は区別してdelivery-manifestとqaへ記録する。視聴やコメント、インストールへの効果は未検証。

公開する場合は、動画IDを得た後にこの答え原稿を実投稿・固定する手段と失敗時の追跡を用意する。未投稿なのにコメント欄に答えがあると報告しない。投稿・固定・公開後の効果観測は制作の完了と別に扱う。
