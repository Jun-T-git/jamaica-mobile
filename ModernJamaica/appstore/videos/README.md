## 制作根拠と素材

`source/core.mov` と `source/modes.mov` は、今回専用に作成した iPhone 17 Pro Max / iOS 26.5 シミュレータで、リポジトリのアプリを実際に操作して収録した原本。
既存の Debug バイナリと現行 Metro の組み合わせで起動。App Store 配信版と完全に一致するビルドの収録であるとは確認していない。
操作方式・表示・正解判定は実アプリ。ゲーム本体のコードは変更していない。

5数字 `[2, 1, 3, 4, 3]` を全て1回ずつ使い、`((3 − 2) ＋ 1) × (4 ＋ 3) = 14` を作った。
App Previewは実画面の全体を維持し、待ち時間をカット。正解時のフレームを最後に1.4秒保持して読み取れるようにした。
検索用は実映像の盤面をトリミングし、編集で再生時間を短縮。最後は冒頭の実フレームにディゾルブして循環させる。
ヘッダーは同じ計算とブランド色を使った独自グラフィック。操作画面の再現ではなく、クリエイティブアセットとして作成。
競合の画像・音楽・映像は使用していない。音声の権利処理を要する素材も含まない。

## 再生成

Python 3 + Pillow、libx264を含むffmpeg、日本語フォントが必要。アプリの依存関係への追加はない。

```sh
FFMPEG=/path/to/ffmpeg python3 render.py
FFMPEG=/path/to/ffmpeg python3 validate.py
```

macOSのヒラギノを利用。別環境では `JAPANESE_FONT=/path/to/font.ttf` を指定。
原本と `render.py` から再生成可能。`build/` は中間生成物としてGit対象外。
字幕・タイミング・配色は `render.py` を編集する。

## App Store Connectへの登録

1. ヘッダー・検索用は Asset Library の Creative Assetsへ。日本語の配置にそれぞれ別ファイルを選ぶ。
2. Header and Search Resultsタブで、ヘッダーと検索の各配置へ割り当てる。共通アセットとして扱わない。
3. App Previewは日本語 / 対応iPhone表示サイズの App Previewsへ。先頭に配置する。
4. ポスター時刻はヘッダー9.5秒、検索10.0秒、App Preview16.6秒を目安に選ぶ。PNGは確認・静止画フォールバック用。App Previewのポスターは動画内フレームを設定する。
5. ConnectのPreviewで切り抜き・セーフエリア・言語・端末別表示を確認してから審査へ提出。

ヘッダー・検索クリエイティブの対象はiOS/iPadOS 27以降。従来のスクリーンショットも維持し、App Previewで旧OSの表示を補う。
ファイルの技術検証とローカル表示確認は完了。ヘッダー・検索用はConnectへのアップロードと処理を通過し、審査待ち。承認と公開配置は未完了。
