# ADR-0013: 復習の解答非表示も計算の木の初期状態にする

- 記録日: 2026-10-06
- 状態: Accepted
- 関連: [ADR-0012](./0012-review-all-played-problems.md) の解答非表示画面を具体化

復習で解答例を隠した時は、目標と元の数字5個をゲーム開始時と同じ盤面風の木に表示する。表示切替では元の数字ノードの位置と盤面の高さを固定し、途中結果ノード・接続線・演算子だけを追加・除去する。

線の交差を減らすため、解答例は元の数字の並びで隣接する項を組み合わせる解を先に探す。見つからない場合は全組み合わせから探し、解答例の提供範囲を狭めない。現行の実装と検証条件は [GAME-CORE.md](../GAME-CORE.md) を参照する。
