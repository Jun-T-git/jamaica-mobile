# ADR-0017: リザルトの操作群を内容に続けて配置する

- 記録日: 2026-10-06
- 状態: Accepted
- 関連: [ADR-0016](./0016-result-action-hierarchy.md) の下側への操作群配置を更新

実画面の確認で、操作群を下端に寄せるとスコア・問題一覧との間に大きすぎる空白が生じた。このためスコア、問題一覧行、再プレイ/メニュー、プレイ詳細トグルと展開内容を上から連続して配置する。余った空間は末尾に残し、要素ごとの中央揃えや行内の整列は維持する。

再プレイを唯一の主要ボタンとする判断、問題一覧のカード全体でのタップ、詳細の折りたたみは維持する。現在の構成は [MONETIZATION.md](../MONETIZATION.md) を参照。
