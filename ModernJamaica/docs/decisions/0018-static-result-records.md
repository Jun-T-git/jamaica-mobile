# ADR-0018: リザルトの記録を操作不要で表示する

- 記録日: 2026-10-06
- 状態: Accepted
- 関連: [ADR-0017](./0017-contiguous-result-layout.md) の折りたたみ式詳細を更新

「プレイの詳細」の展開操作を廃止し、正解がある場合に「今回の記録」を常時表示する。平均回答時間に加え、チャレンジでは正解数・最大コンボ・基準ランク・スコア内訳を示す。薄い区切り線と控えめなテキストを使い、タップする領域と読み取る領域を区別する。

スコア、問題一覧、再プレイ/メニュー、記録の連続配置と、再プレイを単一の主要ボタンとする方針は維持する。正解が 0 問なら情報の乏しい記録領域を省略する。採点や特典・広告条件は変更しない。

現在の表示仕様は [MONETIZATION.md](../MONETIZATION.md) を参照。
