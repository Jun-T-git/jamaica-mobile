# ADR-0005: 匿名の利用状況計測（Firebase Analytics）を導入

- 記録日: 2026-09-19
- 状態: Accepted

## 背景

どこでプレイヤーが離脱しているか（初回で止まるのか、何問目で終わるのか）を測る手段がなく、改善の効果も検証できなかった。一方でこのアプリは「個人情報を収集しない」を方針としている（PHILOSOPHY §6）。

## 決定

Firebase Analytics を導入する。ただし次を守る。

- **広告識別子（IDFA）と連携しない**（Podfile の `$RNFirebaseAnalyticsWithoutAdIdSupport`。ATT ダイアログも出さない）。
- 送るのは匿名のイベントだけ: 画面表示、ゲームの開始/終了（モード・難易度・スコア・正解数など）、正解/スキップ、チュートリアルの開始/完了/スキップ。ニックネーム等のユーザー入力は送らない。
- 計測の失敗はすべて握りつぶし、ゲーム進行に影響させない（不変条件 #6）。

## 影響

- プライバシーポリシー（ルート `docs/index.html`）に利用状況データの記載を追加した。App Store Connect のプライバシー申告にも「使用状況データ」の追加が必要。
- 実装は `services/analyticsService.ts` の薄いラッパに集約。イベントを増やすときもここを通す。
