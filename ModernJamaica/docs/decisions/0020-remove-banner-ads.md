# ADR-0020: バナー広告を全面廃止する

- 記録日: 2026-10-06
- 状態: Accepted
- 関連: [ADR-0008](./0008-purchase-and-rewarded-review.md) のバナー継続方針を更新

## 根拠

今回の判断に共有された AdMob 実績は以下のとおり。金額と eCPM は概数である。

| 期間 | バナー | 全画面広告 |
|---|---|---|
| 2026-08-01〜08-31 | 約 4 円 / 124 表示、eCPM 約 29 円 | 約 9 円 / 5 表示 |
| 2026-09-01〜09-26 | 約 3 円 / 83 表示、eCPM 約 41 円 | 0 表示 |

この観測期間ではバナーの収益寄与が小さい。常設の広告枠を画面から外す判断材料にはなるが、少量サンプルであり、将来の収益水準や広告形式間の優劣を一般化できない。UX 改善や購入増の因果的効果も未検証である。

## 判断

メニュー・ランキング・リザルトを含む全画面からバナー広告を外し、BannerAdView とバナー用 ID/API を削除する。無料ユーザーにもバナーを表示しない。

買い切りの説明は「全画面広告を削除」とし、広告削除とヒント・解答例の特典を維持する。自然な区切りでのインタースティシャルと、ユーザーが選ぶリワード広告は継続する。

## 検証

短期的には観測されていたバナー収益が失われる。総収益/DAU、任意広告の利用、購入、再プレイ・継続率を確認し、表示削除だけで購入が増えると判断しない。現在の運用方針は [MONETIZATION.md](../MONETIZATION.md) を参照。
