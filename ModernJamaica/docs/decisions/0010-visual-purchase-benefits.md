# ADR-0010: 購入特典を短文と大きなアイコンで伝える

- 記録日: 2026-10-05
- 状態: Accepted（理解しやすさを狙った設計。収益効果は未検証）
- 関連: [ADR-0009](./0009-shared-purchase-screen.md) の共通画面・商品・購入/復元フローを維持

## 判断

ユーザーの「シンプルで視覚的な購入画面」という要望に合わせ、短い見出しと「広告なし」「解答例見放題」の大きなアイコンカードを中心にする。小幅画面と文字拡大時は縦並びにする。

無料版との比較・問い合わせは開閉できる詳細へ移す。ただし、解答例の対象は今回のスキップ・未解答問題で次のプレイで一覧が入れ替わる条件は常時表示する。固定フッターにはストア取得の総額、買い切り、月額料金なし、自動更新なしを残す。閉じる・無料継続・復元、状態別の通知も維持する。

表示イベントの layout は `visual_benefits_v2` とし、旧レイアウトと区別する。比較情報に追加操作が必要になるため、詳細の発見しやすさと開閉、文字拡大時の操作性を確認する。

## 参考と適用範囲

[RevenueCat の購入画面改善事例](https://www.revenuecat.com/blog/growth/paywall-redesigns-case-studies) は担当者による報告で、免許学習アプリとパーティーゲームの長文を短く整理し、ゲームではイラスト等で視覚的に伝えた事例を含む。プラン配置・価格提示・トライアル切替なども同時に変更しており、短文化や視覚化だけの効果は分離できない。本アプリの購入率や収益の予測には使わない。

採用するのは特典を短く視覚的に伝える考え方だけ。トライアル切替やサブスクのプラン構成は導入しない。実際の影響は入口別の購入イベントと [MONETIZATION.md](../MONETIZATION.md) の指標で確認する。
