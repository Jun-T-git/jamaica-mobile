# ADR-0011: 購入画面を説明中心の表現にする

- 記録日: 2026-10-05
- 状態: Accepted
- 関連: [ADR-0010](./0010-visual-purchase-benefits.md) の見出し・アイコン強調方針を更新

視覚化した購入画面に対し、ユーザーから「胡散臭い」というフィードバックがあった。宣伝的な見出しと見出し上の重複ラベルを外し、未購入時は入口を問わず「広告を削除」とする。無限マークを本のアイコンに替え、アイコンとカードのタイトルを控えめな大きさにする。

2 特典のカード、小幅/文字拡大時の縦並び、開閉詳細、常時見える対象条件、価格と買い切り条件、無料継続・閉じる・復元は維持する。商品の内容を簡潔に説明するための調整であり、収益効果は未検証。現状は [MONETIZATION.md](../MONETIZATION.md) を参照する。
