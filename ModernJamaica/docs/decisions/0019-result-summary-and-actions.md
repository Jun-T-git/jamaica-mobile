# ADR-0019: リザルト上側を記録、下側を操作にまとめる

- 記録日: 2026-10-06
- 状態: Accepted
- 関連: [ADR-0017](./0017-contiguous-result-layout.md) の連続配置を更新し、[ADR-0018](./0018-static-result-records.md) の記録常時表示は維持

上側にスコアと今回の記録、下側に復習カードと「もう一度」「ホームに戻る」をまとめる。読み取る情報と次の行動を選ぶ領域を整理するための配置である。

復習カードは「解答例を見る・復習する」とし、全体のタップで無料の問題一覧へ進む。未購入でリワード権利がない場合は、動画視聴で解答例が 1 時間見放題になることをカード内で短く案内する。動画視聴の操作自体は問題詳細に置く。

再プレイを単一の主要ボタンとし、正解 0 問では記録領域を省略する。無料練習や購入・広告条件は維持する。現在の構成は [MONETIZATION.md](../MONETIZATION.md) を参照。
