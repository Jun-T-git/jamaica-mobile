# ADR-0006: チャレンジの時間ボーナスを逓減させ、上級者でも 1 ゲーム約 3 分で終わるようにする

- 記録日: 2026-09-19
- 状態: Accepted

## 背景

チャレンジモードは正解のたびに固定秒数（難易度別）を残り時間へ無制限に加算していた。残り時間は「解答にかかった時間 − ボーナス」の積み重ねなので、平均解答時間がボーナスより短いプレイヤーは残り時間が増え続け、**ゲームがいつまでも終わらない**。チャレンジの意図は「短時間の集中・スコア競争」（PHILOSOPHY §5）であり、長く遊べるほどスコアが伸びるランキングは実力ではなく根気の勝負になる。上級者でも 1 ゲーム 3 分程度に収めたい。

## 決定

- **正解ボーナスを正解のたびに減らし、小さな下限（1 秒）で下げ止める。** 下限は人が 1 問を解ける時間（5 数字の結合に 12 タップ必要）よりずっと短いので、どれだけ速く解いても残り時間はやがて尽きる。上級者の速さ（かんたん 5 秒 / ふつう 6 秒 / むずかしい 10 秒）で 3 分前後に収まるよう数値を決めた。むずかしいは初期時間も 90 秒から 60 秒に短くした（上級者で約 2.5 分）。
- 下限を 0 にすれば 1 ゲームの長さに厳密な上限（初期時間 + ボーナスの総和）ができるが、終盤に「正解しても何も増えない」区間が続くのを避けるため、わずかな下限を残した。その代わり最長時間は腕前に少し依存する（かんたんを 4 秒/問で解き続けると約 3.2 分）。
- かんたん・ふつうは初期時間を変えず、ふつう・むずかしいは最初のボーナスも変えていないので、序盤の体験は大きく変わらない。
- 正解オーバーレイに得た秒数（「+N秒」）を出し、減っていくことをプレイヤーに見せる。
- また、正解演出中に Undo で最後の結合を戻してつなぎ直すと、同じ問題でスコアと時間ボーナスを何度でも取り直せる抜け穴があったため、Undo は組み立て中のみ有効にした。

検討して採らなかった案:

- 数問ごとの緩い逓減 + 大きめの下限 + 残り時間の上限: 上級者で 6〜7 分かかり長すぎた。上限は速いプレイヤーほどボーナスを捨てることになり、表示される秒数も分かりにくい。
- 問題数に応じた難易度上昇: 難易度を選ぶ設計と衝突し、調整コストが高い。
- 最大問題数/最大時間での打ち切り: 上位スコアが同値に並び、終わり方の達成感を別途設計する必要がある。

## 影響

- 時間ルールが変わるため、変更前後のスコアは比較できない。ただし [0004](./0004-ranking-v2-anonymous-auth.md) の `userScoresV2` / `_v2` ハイスコアキーは未リリースで、この変更と同時にリリースされるため、**追加のバージョン分離はしない**。V2 のリリース後に時間ルールを再び変える場合は、ランキングの分離（シーズン切り替え等）を検討すること。
- 1 ゲームの問題数が最速級でも数十問に収まるので、ランキングのスコア上限（`firestore.rules`）に届く心配がなくなった。
- 上級者のセッション長はテストで難易度ごとに検証する。数値を調整するときはこのテストが安全網になる。
