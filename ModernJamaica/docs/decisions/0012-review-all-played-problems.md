# ADR-0012: このプレイの全問題を答えを隠して復習する

- 記録日: 2026-10-06
- 状態: Accepted
- 関連: [ADR-0008](./0008-purchase-and-rewarded-review.md) の解答例対象を拡張

正解した問題も学び直せるよう、復習一覧にはそのプレイで正解・スキップ・未解答となった問題を発生順に含める。各行に結果を示し、「解けなかった」問題だけに絞り込めるようにする。

問題一覧と元の数字・目標は誰でも見られる。解答例は問題を開いた時点では隠し、買い切り特典かリワード閲覧権利がある場合にだけ、ユーザーの操作で表示・非表示を切り替える。別の問題へ移った時や閲覧期限が切れた時も隠す。正解問題の木はプレイヤーが実際に組んだ式の再現ではなく、その問題の解答例である。

復習記録は次のプレイで置き換わるメモリ上の一覧とし、採点・問題生成・ランキングへ影響させない。現行の挙動と検証条件は [GAME-CORE.md](../GAME-CORE.md) と [MONETIZATION.md](../MONETIZATION.md) を参照する。
