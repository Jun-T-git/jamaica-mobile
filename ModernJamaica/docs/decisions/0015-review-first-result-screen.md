# ADR-0015: リザルトから復習の一覧へ進みやすくする

- 記録日: 2026-10-06
- 状態: Accepted

## 判断

リザルトはスコア、復習カード、再プレイ/メニュー、開閉式のプレイ詳細の順にする。「問題一覧を見る」を主要な操作にし、基準スコア・平均回答時間・コンボ・スコア内訳は詳細にまとめる。結果を見て次の行動を選ぶ際の情報量を減らすためであり、採点方法は変更しない。

復習カードの動画視聴ボタンを外し、各問題の詳細でヒント・答えが必要になった際の導線へ集約する。無料の一覧・練習に進む前の選択肢を減らす一方、動画の訴求機会も減るため、収益効果は未検証とする。購入リンクは控えめな 1 行にし、問題一覧が次のプレイで入れ替わる注意は一覧内に置く。

商品・権利・広告頻度の条件は維持する。現在の仕様と計測方針は [MONETIZATION.md](../MONETIZATION.md) を参照。
