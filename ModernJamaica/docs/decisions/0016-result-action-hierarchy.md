# ADR-0016: リザルトの主操作を再プレイに統一する

- 記録日: 2026-10-06
- 状態: Accepted
- 関連: [ADR-0015](./0015-review-first-result-screen.md) の配置・主操作方針を更新

リザルト全体の中央寄せをやめ、上からスコアと問題一覧へのコンパクトな行を置く。問題一覧はカード全体をタップして開く方式とし、独立した強調色の主要ボタンにはしない。

プレイ詳細と再プレイ/メニューを下側にまとめ、再プレイだけを主要ボタンにする。問題一覧の見つけやすさを保ちつつ、強く見える操作が競合しないようにする判断である。詳細の折りたたみ、各問題の詳細への動画導線集約、無料練習と購入特典は維持する。

購入率・広告収益・再プレイ率への効果は未検証。現在の実装は [MONETIZATION.md](../MONETIZATION.md) を参照。
