# ADR-0014: 復習で再挑戦し、ヒントを3段階で見る

- 記録日: 2026-10-06
- 状態: Accepted
- 関連: [ADR-0013](./0013-review-tree-initial-state.md) の復習盤面を操作可能にする

復習の問題詳細は、元の数字ノードを使って再び計算できる練習盤面にする。練習ではノード・演算子・ノードの順に選んで計算し、1手戻す・最初から解き直す操作を提供する。練習の状態は本番のゲーム状態から独立させ、スコア・時間・ランキング・過去の正誤を変更しない。

解答例の最初の1・2・3計算をそれぞれヒント1・2・3として段階表示し、答えでは4計算すべてを表示する。ヒント・答えは練習の木とは別のプレビューであり、練習中の操作を保持したまま戻れる。練習は無料、ヒントと答えの表示には買い切り特典または有効なリワード閲覧権利を必要とする。現行仕様は [GAME-CORE.md](../GAME-CORE.md) と [MONETIZATION.md](../MONETIZATION.md) を参照する。
