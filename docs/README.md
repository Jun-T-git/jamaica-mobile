# ジャマイカの木 — プライバシーポリシー

`index.html` はモバイルアプリ「ジャマイカの木」のプライバシーポリシーです。App Store に登録されている URL とアプリ内リンクは `https://modern-jamaica.web.app/` に統一しています。ルートの `firebase.json` により、このディレクトリを Firebase Hosting に公開します。GitHub Pages からも同じファイルを配信できます。

アプリはゲームの進行状況を端末に保存し、ランキング、利用状況の分析、広告、アプリ内購入に Firebase、Google AdMob、Apple StoreKit を使用します。取扱いの詳細と問い合わせ先は `index.html` を参照してください。広告や購入に関する実装を変更した場合は、公開前に本文と App Store のプライバシー申告を再確認します。
